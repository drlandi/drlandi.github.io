I spent 25 years keeping mission-critical systems alive — carrier-grade wireless networks,
signaling infrastructure, prepaid databases running on Solaris and HP-UX, across telecom
deployments in six countries. The discipline that comes from that world — SLA management,
ITIL, eTOM, the assumption that failure is not hypothetical — is the foundation everything
else here is built on.

I'm now retooling deliberately into cloud-native and modern software engineering. That means:

- **42 São Paulo** — an intensive, project-based systems programming curriculum: C,
  algorithms, memory management, Unix/Linux internals, peer-reviewed code with no lectures
  and no shortcuts.
- **AWS architecture, hands-on** — WAF, CloudFront failover, API Gateway, Lambda, DynamoDB,
  SQS, CloudWatch. Not tutorials — live, tested, failure-injected systems.
- **AI-assisted engineering** — production patterns for LLM-backed applications, local model
  deployment, and applying AI tooling inside real pedagogical work.

I also teach. At CIEBP, a specialized educational unit within a São Paulo state public school,
I build activity series that bring computational thinking — unplugged programming, AI literacy —
into classrooms that don't usually get access to it.

If you want the long version, my resume is [here](/resume.pdf) — but this site exists to show
the work directly rather than describe it.
